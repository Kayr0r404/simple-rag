# Pebble CLI

Install with `brew install pebble` or `pipx install pebble-cli`.

Create a note with `pebble new "title"`. Search notes with `pebble find <query>`. Pin a note with `pebble pin <id>`.

Export your notes with `pebble export --format md`, `pebble export --format pdf`, or `pebble export --format json`.

Notes are stored locally in `~/.pebble/notes`. Add tags inline by writing #tag in the note body.

There is no web app. Pebble is available as a CLI and a desktop app only.
